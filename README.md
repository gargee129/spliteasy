# SplitEasy

A simple, mobile-friendly expense splitter for flatmates and friends. Add shared expenses, see who owes what, and settle up with the fewest possible payments.

**Live demo:** https://gargee129.github.io/spliteasy/

## Features

- Add and remove people
- Log expenses in ₹ with who paid and who it's split between
- View and delete past expenses
- See each person's balance (owes or is owed)
- "Settle up" suggestions that minimize the number of payments
- Data saved in your browser (localStorage), so it survives a refresh
- Mobile-first design with automatic dark mode

## How to use

1. Open the live demo or download `index.html` and open it in any browser.
2. Add the people sharing expenses.
3. Add expenses as they happen.
4. Check the Balances and Settle up sections to see who pays whom.

## Built with

- HTML, CSS and vanilla JavaScript (single file, no dependencies)
- Vibe coded with NVIDIA Nemotron

## Limitations

Data is stored only in your own browser, so it isn't shared between devices or people.
